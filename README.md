# FITZONE

Website Fitness & Gym frontend untuk Visual Studio Code.

## Cara menjalankan
1. Buka folder FITZONE di Visual Studio Code.
2. Buka `index.html`.
3. Jalankan dengan Live Server (disarankan), atau buka file HTML di browser.

## Struktur
- index.html — struktur halaman
- style.css — desain dan responsive layout
- script.js — interaksi, BMI, timer, modal, theme, form

Catatan: website ini adalah frontend demo. Membership dan contact form belum terhubung ke database/backend.
